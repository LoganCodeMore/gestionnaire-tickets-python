# Gestionnaire de tickets informatiques

Premier projet Python réalisé dans le cadre de ma formation personnelle.

## Objectif

Créer une application en terminal permettant de gérer simplement des machines et leurs incidents informatiques.

## Fonctionnalités prévues pour la V1

- Ajouter une machine
- Afficher les machines
- Créer un ticket associé à une machine
- Afficher les tickets
- Modifier le statut d'un ticket
- Enregistrer la gravité de l'incident

## Statuts disponibles

- Nouveau
- En cours
- Résolu
- Fermé

## Niveaux de gravité

- Basse
- Moyenne
- Haute
- Critique
